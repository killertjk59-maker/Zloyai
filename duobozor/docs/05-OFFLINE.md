# DuoBozor — Онлайн ё оффлайн?

**Ҷавоби кӯтоҳ:** ❌ на «танҳо онлайн», ❌ на «пурра оффлайн» —
✅ **online-first + offline-tolerant**.

Барнома **бе интернет кушода мешавад** ва кор мекунад: каталоги кэшшуда, сабад,
фармоишҳои кӯҳна, профил. Аммо **пул ҳеҷ гоҳ оффлайн ҳаракат намекунад** —
пардохт, релизи escrow, payout ва ҳамроҳшавӣ ба гурӯҳ мутлақо онлайн талаб мекунанд.

---

## 1. Чаро интихоби «пурра оффлайн» барои маркетплейс хатарнок аст

| Хатaр | Натиҷа |
|---|---|
| Нархи кэшшуда кӯҳна шуд | Харидор 149 мебинад, дар ҳақиқат 165 → баҳс, бекоркунӣ |
| Захира тамом шуд, вале дар кэш ҳаст | Фармоиш қабул мешавад, баъд бекор → бадномии фурӯшанда |
| Ду пардохти як фармоиш (ретрай) | Пул ду маротиба гирифта мешавад → баргардонӣ + шикоят |
| «Гирифтам» оффлайн пахш шуд | Escrow кушода мешавад бе тасдиқи воқеии қабул → фиреб |
| Таймери гурӯҳ дар дастгоҳ | Соати телефон тағйир дода шуд → гурӯҳи «пурра» бе маблағ |

Бинобар ин: **оффлайн = хондан + навбат; онлайн = пул.**

---

## 2. Матритса: чӣ дар ҳар ҳолат кор мекунад

| Функсия | Оффлайн | Чӣ нишон медиҳем |
|---|---|---|
| Кушодани барнома (cold start) | ✅ | Профил аз кэш, «охирин навсозӣ: 2 соат пеш» |
| Feed / каталог / ҷустуҷӯ | ✅ кэш | Танҳо он чӣ кэш шудааст; ҷустуҷӯ маҳаллӣ (SQLite FTS) |
| Корти маҳсулот | ✅ кэш | Бо нишони «нарх метавонад тағйир ёбад» |
| Суратҳо | ✅ диск | `expo-image` disk cache, LRU 300 МБ |
| Сабад (илова/тағйир) | ✅ + навбат | «Дар навбат: 2 амал» |
| Дӯстдоштаҳо / суроға / профил | ✅ + навбат | Оптимистӣ, синхрон ҳангоми пайваст |
| Баҳо гузоштан | ✅ + навбат | «Ҳангоми пайваст нашр мешавад» |
| Фармоиш (нақдӣ / ҳамён) | ⚠️ навбат | Танҳо баъди тасдиқи захира дар сервер |
| **Пардохт бо корт / Alipay** | ❌ | Тугма хомӯш + «Барои пардохт интернет лозим» |
| **OTP / вуруди якум** | ❌ | Тугма хомӯш |
| Вуруди такрорӣ (refresh token) | ✅ 30 рӯз | Ҷаласа аз SecureStore |
| **«Гирифтам» → релизи escrow** | ❌ | Хомӯш, бо шарҳ |
| **Ҳамроҳшавӣ ба гурӯҳ** | ❌ | Таймер дар сервер; оффлайн = хато |
| Пайгирии фармоиш | ✅ кэш | Охирин ҳолати маълум |
| **Баҳс кушодан** | ❌ | SLA 24с; вақти сервер муҳим |
| **Payout (фурӯшанда)** | ❌ | Ҳаракати пул |
| Чат бо дастгирӣ | ⚠️ навбат | Паёмҳо дар навбат, вале фиристодани аввал онлайн |

> Қоидаи оддӣ: **агар амал `amount > 0` дошта бошад — онлайн.**
> Ин дар код маҷбуран иҷро мешавад: `REQUIRES_NETWORK` дар `expo/lib/offlineQueue.ts`
> ба навбат гузоштани чунин амалро **хато медиҳад** (санҷида шуд).

                │                              │

### 3.1 TTL-и кэш (на ҳама чиз як хел)

| Домен | TTL | Сабаб |
|---|---|---|
| Категорияҳо | 7 рӯз | Тағйирёбиаш кам |
| Маҳсулот (ном, сурат, тавсиф) | 24 соат | Статикӣ |
| **Нарх** | 5 дақиқа | Ҳассос — ҳамеша тафтиш дар checkout |
| **Захира** | 60 сония | Нодурустӣ = фармоиши бекор |
| Профил | 1 соат | |
| Фармоишҳо | 10 дақиқа | Ҳолат метавонад иваз шавад |
| Бақия/escrow | 30 сония | Молиявӣ |

### 3.2 Қоидаи тиллоӣ ҳангоми checkout

Ҳангоми кушодани checkout барнома **ҳатман** аз сервер нарх ва захираро мепурсад:

```
GET /api/v1/checkout/validate  { items[], coupon }
→ 200 { prices: {149.00}, stock_ok: true,  price_version: "v2" }
→ 409 { conflicts: [{variantId, old_price:149, new_price:165, ...}] }
```

Агар нарх тағйир ёфта бошад — корбар мебинад:
> «Нархи мол тағйир ёфт: 149 → 165 с. Қабул мекунед?» [Ҳа] [Не, хориҷ кун]
Ва амали кӯҳна ба `conflict` мегузарад, на `dead`.

## 4. Код

### 4.1 `expo/lib/offlineQueue.ts` — навбати амалҳо

```ts
const queue = new OfflineQueue(storage, { maxAttempts: 6, baseDelayMs: 2000 });

await queue.load();                              // ҳангоми кушодани барнома
NetInfo.addEventListener(({ isConnected }) => {
  if (isConnected) queue.flush(sendToApi);       // ҳангоми пайваст
});

// амали бехатар:
await queue.enqueue('cart.add', 'POST', '/api/v1/cart/items', { variantId, qty });

// амали хатарнок — ҲАТМАН хато медиҳад:
await queue.enqueue('payment.card', 'POST', '/pay', {});
// → Error: «payment.card» бе интернет иҷро намешавад — ба навбат намегузорем
```

Ҳолатҳои амал: `pending → sending → (нест | retried | conflict | dead)`

| Ҷавоби сервер | Рафтор |
|---|---|
| 2xx | аз навбат нест мешавад |
| шабака нест | `attempts++`, backoff `2s → 4s → 8s → …` (max 5 дақ) + jitter |
| 5xx / 429 | ҳамон тавр, вале то `maxAttempts` |
| **409** | `conflict` — корбар тасдиқ мекунад (`resolveConflict(id, true/false)`) |
| 400 / 403 / 404 / 422 | `dead` — ислоҳ кардан мумкин нест, ба корбар нишон медиҳем |

### 4.2 React Query — кэши устувор

```ts
import { PersistQueryClientProvider } from '@tanstack/react-query-persist-client';
import { createSyncStoragePersister } from '@tanstack/query-sync-storage-persister';
import { MMKV } from 'react-native-mmkv';

const mmkv = new MMKV({ id: 'rq-cache', encryptionKey: DEVICE_KEY });

const persister = createSyncStoragePersister({
  storage: {
    getItem: (k) => mmkv.getString(k) ?? null,
    setItem: (k, v) => mmkv.set(k, v),
    removeItem: (k) => mmkv.delete(k),
  },
});

<PersistQueryClientProvider
  client={queryClient}
  persistOptions={{ persister, maxAge: 24 * 3600 * 1000, buster: APP_VERSION }}
>
```

`buster: APP_VERSION` — муҳим: баъд аз навсозии барнома кэши кӯҳна партофта мешавад.

### 4.3 NetInfo + AppState

```ts
useEffect(() => {
  const unsubNet = NetInfo.addEventListener((s) => {
    setOnline(!!s.isConnected);
    if (s.isConnected) syncAll();          // flush + invalidate + pull
  });
  const sub = AppState.addEventListener('change', (st) => {
    if (st === 'active') syncAll();        // баргашт аз background
  });
  return () => { unsubNet(); sub.remove(); };
}, []);
```

## 5. Амният дар ҳолати оффлайн

| Хавф | Чора |
|---|---|
| Кэши нарм дар диск | MMKV бо `encryptionKey` дар SecureStore/Keystore |
| Токен дар кэш | Токен танҳо дар `expo-secure-store`, на дар MMKV |
| Навбати амалҳо дуздӣ шуд | Дар навбат ҳеҷ PAN, ҳеҷ OTP, ҳеҷ парол нест |
| Дастгоҳ гум шуд | `POST /auth/sessions/revoke-all` аз дастгоҳи дигар; refresh 30 рӯз |
| «Гирифтам» оффлайн | Дар навбат нест — ҳатман онлайн + OTP |
| Кэши кӯҳна баъд аз logout | `queryClient.clear()` + `mmkv.clearAll()` |

## 6. Ҳаҷми нигоҳдорӣ

| Чиз | Ҳадд |
|---|---|
| SQLite (каталог) | 200 МБ, LRU |
| Суратҳо | 300 МБ, LRU |
| MMKV (кэши API) | 20 МБ |
| Outbox | 500 амал (баъд аз он — dead-letter ва огоҳӣ) |

вагарна `OutOfMemory` медиҳад.
