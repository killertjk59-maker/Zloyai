## 3. Ҷараёнҳои асосӣ (user flows)

### 3.1 Гурӯҳхаридии муваффақ
```
Home → Маҳсулот → «Гурӯҳ соз» → интихоби андоза/ранг
   → пардохт (escrow) → экран «Гурӯҳи ман» → даъвати дӯст (WA/TG)
   → дӯст линкро мекушояд → «Ҳамроҳ шав» → пардохт
   → гурӯҳ пурра → фурӯшанда фармоишҳоро мебинад → фиристодан
   → харидорон «Гирифтам» → релизи escrow ба фурӯшанда + комиссия
```

### 3.2 Гурӯҳ ноком шуд
```
24 соат гузашт → статус failed → refund-и худкор ба ҳамёни харидорон
   → notification + купони тасаллӣ (5%) барои кӯшиши навбатӣ
```

### 3.3 Баҳс
```
Харидор «Баҳс» → сабаб + сурат → status DISPUTED, escrow frozen
   → менеджер дар 24 соат: пурра баргардонӣ / қисмӣ / ба фурӯшанда
   → ҳал: refund ё release + ҷарима ба рейтинги фурӯшанда
```

### 3.4 Payout ба фурӯшанда
```
Escrow released → ҳамёни фурӯшанда: available +906.20
   → «Баровардан» → тасдиқи админ (4-eye агар >2000)
   → SENT бо bank_ref → notification + чек
```

## 4. Компонентҳои асосӣ (React Native)

| Компонент | Тавсиф | Ҳолатҳо |
|---|---|---|
| `<PriceTag>` | нархи гурӯҳӣ + кӯҳна + `−38%` | default / flash / out-of-stock |
| `<GroupBuyCard>` | таймер, аватарҳо, progress, «N нафар монд» | open / почти / full / expired |
| `<JoinButton>` | «Гурӯҳ соз» / «Ҳамроҳ шав» / «Пурра» | 3 вариант |
| `<EscrowBadge>` | 🛡 «Пул дар escrow» | small / banner / receipt |
| `<TierPicker>` | 1 / 2 / 5 нафар | selected |
| `<OrderTimeline>` | 5 қадам | done / now / future |
| `<WalletCard>` | бақия + escrow + кэшбэк | buyer / seller |
| `<RoleGate>` | намоиш аз рӯи нақш | — |
| `<MoneyInput>` | бо `tabular-nums`, TJS mask | error |
| `<KpiCard>` | барои панели админ | up / down / alert |

**Қоидаҳои accessibility:** контраст ≥ 4.5:1, майдони пахш ≥ 44×44, ҳамаи
тугмаҳо `accessibilityLabel`, таймерҳо на танҳо ранг балки матнӣ ҳам мегӯянд.

**Empty/error/loading:** ҳар экран 3 ҳолат дорад — skeleton, empty (бо CTA),
error (бо «Аз нав кӯшиш кун»), ва offline (бо кэши охирин).

## 5. Локализатсия (tj / ru)

- `i18next` + `react-i18next`, файлҳо `locales/tj.json`, `locales/ru.json`
- Калидҳо: `home.greeting`, `product.group_cta`, `escrow.notice_body`…
- Рақамҳо ва санаҳо: `Intl.NumberFormat('tj-TJ')`, `Intl.DateTimeFormat`
- Асъор: `1 240 c.` (тоҷикӣ) / `1 240 c.` (русӣ — ҳам ҳамин, то фарқ накунад)
- Матнҳои SMS: ҳарду забон, ≤70 аломат барои як SMS
- Ҳеҷ гоҳ матн дар компонент «сакт» намешавад — танҳо калид

## 6. Чӣ дар mockup исбот шудааст

1. **Модели нарх** — зинаҳои 1 / 2 / 5 нафар дар экрани маҳсулот.
2. **Гурӯҳ ҳамчун объекти асосӣ** — экрани алоҳида бо давраи прогресс ва даъватнома.
3. **Escrow на танҳо функсия, балки элементҳои дизайн** — дар checkout, дар
   пайгирӣ, дар ҳамён. Ин фарқияти асосии мо аз рақибон аст.
4. **Ҷараёни пул дар як нигоҳ** — блоки «Ҷараёни пул — имрӯз» дар панели админ:
   қабул → релиз → комиссия → бонуси менеджер → баргардонӣ.
5. **4 нақш дида мешавад** — харидор (э. 1–6), фурӯшанда (дар ҳамён/дашборд),
   менеджер ва админ (э. 7).
