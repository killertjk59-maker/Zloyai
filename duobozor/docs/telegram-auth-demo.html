⚡ Чӣ тавр кор мекунад

1. Дар @BotFather → /newapp → URL-и веб-версияи шуморо медиҳед.
2. Корбар тугмаи менюро дар бот пахш мекунад.
3. Барнома дар дохили Telegram кушода мешавад ва window.Telegram.WebApp.initData мегирад.
4. Ин сатр ба сервер меравад — сервер бо bot_token имзоро тафтиш мекунад.
5. auth_date бояд < 5 дақиқа бошад (replay-guard).
